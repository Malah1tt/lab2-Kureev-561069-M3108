# Общее описание решения

Данный проект содержит в себе 4 программы, написанные на языке *python*, содержащие в себе две функции: для вычеления **площади** и **перемитра** геометрической фигуры. Каждая программа названа в честь фигуры для которой корректно применимы функции внутри ее.

# Описание функционала отдельных программ

## circle.py

Данная программа содержит функции, вычисляющие площадь и периметр круга.

### Функция area

Возвращает площадь круга по его радиусу.

**Параметры:**

- r (int) - радиус круга

**Возвращаемое значение:**

- число - площадь круга

Пример вызова:

```python
>>> area(5)
78.5
```

### Функция perimeter

Возвращает периметр круга по его радиусу.

**Параметры:**

- r (int) - радиус круга

**Возвращаемое значение:**

- число - периметр круга

Пример вызова:

```python
>>> perimeter(5)
31.4
```

## rectangle.py

Данная программа содержит функции, вычисляющие площадь и периметр прямоугольника.

Возвращает площадь прямоугольника по его длине и ширине.

**Параметры:**

- a (int) - длина прямоугольника
- b (int) - ширина прямоугольника

**Возвращаемое значение:**

- число - площадь прямоугольника

Пример вызова:

```python
>>> area(4, 5)

```

### Функция perimeter

Возвращает периметр прямоугольника по его длине и ширине.

**Параметры:**
- a (int) - длина прямоугольника
- b (int) - ширина прямоугольника

**Возвращаемое значение:**

- число - периметр прямоугольника

Пример вызова:

```python
>>> perimeter(4, 5)
18
```

## triangle.py

Данная программа содержит функции, вычисляющие площадь и периметр треугольника.

### Функция area

Возвращает площадь треугольника по его основанию и высоте.

**Параметры**
- a (int) - основание треугольника
- h (int) - высота треугольника

**Возвращаемое значение:**

- число - площадь треугольника

Пример вызова:

```python
>>> area(6, 4)
12
```

### Функция perimeter

Возвращает периметр треугольника по трём его сторонам.

**Параметры**
- a (int) - длина первой стороны треугольника
- b (int) - длина второй стороны треугольника
- c (int) - длина третьей стороны треугольника

**Возвращаемое значение:**

- число - периметр треугольника

Пример вызова:

```python
>>> perimeter(3, 4, 5)
12
```
